# ENGRENA

Site de testes: https://cristianlf23.github.io/engrena-site/?v=1.12

Versão 1.12: introdução fullscreen cobrindo toda a página a cada carregamento, fora da área do hero. Marca animada, saída suave em cortina, Pular introdução e Escape. Conteúdo protegido por inert e rolagem bloqueada apenas durante a introdução. Foco por teclado e saída de segurança independente do script principal.

Sem JavaScript, movimento reduzido e economia de dados mantêm acesso direto. Controles de replay/comparação apenas no desktop. Elementos de interface usam SVG/CSS, sem emojis. Nenhuma dependência nova.

Revisão 1.11 preservada: mobile, jornadas azuis, faixa contínua, cards, gráficos sincronizados e engrenagem cromada com 24 dentes que acompanha o scroll e se encaixa no contador.

Formulário e contatos continuam demonstrativos, sem transmissão ou persistência. Feedbacks fictícios estão identificados e dados históricos mantidos.
